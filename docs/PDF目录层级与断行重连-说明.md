# PDF 目录层级识别 + 断行重连 · 功能说明

> 版本：v1.7.8　日期：2026-11-26
> 触发：用户要求「识别 PDF 目录层级结构（含内容）」+「同一句话被 PDF 换行切开后自动合并为连贯一句」。

---

## 一、架构位置（守冻结内核）

`CAPABILITY_CONTRACT.md` §1 规定 `extract.py` 探测/分流/提取/汇总/对账主流水线**一行不动**。
本功能全部落在独立后处理层：

```
extract.py（冻结内核）→ 产出 md + 锚点
        ↓
app.py 任务成功回调
        ├─ OCR 后处理（已有）
        └─ pdf_layout 后处理（本功能）→ derived/<stem>_目录与连贯.md
```

- 新模块 `core/pdf_layout.py`：纯文本处理，不重新解析 PDF。
- 新产物落 `derived/`，**不写 `out/md/*.md`**（阶段 1 件数对账红线）。
- `build.spec` hiddenimports 加 `pdf_layout`（打包可用）。

## 二、断行重连（reflow_lines）

中文 PDF 断行可以切在**任意词中间**（「我感|到自己」「开|发人员」），只靠标点穷举覆盖不了。
采用三层保守判据（宁可漏连，不可错连）：

| 判据 | 说明 |
|---|---|
| 强证据① 悬挂修饰语结尾 | 上一行以「的/了/和/与/为/把/被/从/对/以/逗号…」结尾 → 话没说完 |
| 强证据② 接近满行 | 上一行 ≥30 字且无终止标点 → 排版学上判定「被栏宽切断」的可靠信号 |
| 中证据 双字承接词 | 下一行以「然而/因此/以及/同时/其中…」开头 |

防误伤护栏：
- 终止标点（。！？；：）结尾 → 段落边界；空行 → 段落边界；
- 标题行（第X章/数字小节）、页码、纯英数行、水印行 → 不参与合并；
- 下一行 <12 字且无终止标点 → 疑似小节标题，不合并（保住「快速分析和小结277」这类标题、CIP 独立条目）；
- 连续合并上限 3 行（防止整页连成巨型段落）。

实测（软技能 OCR 稿 2068 行）：合并 693 行、0 个超长行（最长 181 字）、
关键断句「我感|到自己被困…」正确连成「我感到自己被困在公司里工作…」；
CIP 三条目「[美]John…／中国工信出版集团／人民邮电出版社」保持独立。

## 三、目录层级还原（build_toc）

只认明确模式，识别不出就返回空列表（诚实降级，不猜目录）：
- `第X篇/部/卷` → level 1；`第X章` → level 2；`附录X` → level 1；
- `X.X 小节` → level 3；
- 章名被 OCR 拆两行时（`第2章` + `从非同凡响开始…`）自动补全；
- 同一标题在目录页 + 正文页眉重复出现 → 只留首次；
- 纯数字行（CIP「1 4 000 20」、价格「59.00」）识别为噪声，不算目录项。

实测：OCR 稿识别出 86 条正确层级（篇→章）；双栏错乱的内置解析文本识别出 0 条（诚实降级）。

## 四、接入与幂等

- `app.py::_pdf_layout_postprocess(job)` 在 OCR 后处理之后调用，独立 try 块，
  任何异常只写日志、绝不影响主任务状态；
- 来源优先级：`derived/` 下 OCR 产物 > `out/md/` 下阶段 1 产物（只读）；
- 文件名匹配做归一化（书名号/冒号被清洗成 `_`、编号前缀不影响）；
- 目标文件已存在且内容一致时跳过；写盘走 `.tmp` + `os.replace` 原子替换；
- 新产物头部有 8 字段风格的 `source` 注释，可回溯源文件。

## 五、实测驱动的缺陷修复（v1.7.9）

架构师用桌面两个 PDF 端到端实测（软技能 27MB 走 OCR 885 秒 + 扫描版 40MB 降级），
三专家（质量/健壮性/架构）轮番审视，发现并修复以下真实 bug：

| 严重度 | 缺陷 | 实测证据 | 修复 |
|---|---|---|---|
| **P1 致命** | OCR 产物写在 `outdir` 根，模块却只在 `derived/` 找 → 主来源永远落空 | 端到端日志「目录0项/合并18行」（处理的是双栏错乱内置产物） | `_pdf_layout_sources` 两处都查，优先 outdir 根精确同名 |
| P1 | 文件名子串误匹配：`a.pdf` 匹到 `a2.md` | 代码审查 | 改严格匹配（清洗后相等 / 数字编号前缀+同名） |
| P1 | 单件异常中断整批 | 代码审查 | 循环内 try/except 逐件隔离；`.tmp` 写盘失败清理 |
| P0 | `clean_ocr` 只跑 `[:2]` 条水印模式 → `www.epul`/`WWW.ep` 残留 | `clean("www.epul")` 原样返回 | 跑全部模式 + fragment 正则修为 `www.ep\w*` |
| P0 | `步社区→异步社区` 自我叠加成 `异异异步社区` | 实测输出 `异异异步社区全站…` | 先修 `异异步社区`，再用负向前瞻 `(?<!异)步社区` |
| P1 | CIP「书名原文」「使用方法」结构化行被合并 | 「即可使用使用方法：…」黏连 | `_STRUCTURED_LINE_RE` 挡住字段行 |
| P1 | HTML 注释行 / 省略号结尾被合并 | 代码+实测 | 注释行加 `_is_blocked`；省略号/破折号列入终止符 |
| P2 | 广告页脚/价格行被当目录项 | 实测抓到「1 4 000 20」「59.」 | 小节必须有中文或 ≥4 字母标题 |

修复后端到端复测：**目录 86 项、断行合并 689 行**（此前 0/18），
关键句「我感到自己被困在公司里工作」连贯；实测 10 项缺陷全部有守护测试锁定。
