# S14 · UI 信息架构重组（说明）

> 日期：2026-11-22
> 基线：v1.2.3
> 触发：用户对界面布局不满——「同类型功能拆得乱七八糟，找对应功能难」

---

## 一、问题诊断

把 `ui/index.html` 的 7 个导航页与全部卡片拆开看，问题有三：

1. **一条流水线被拆成三个平级页**：加工（转 md）→ 精读（提纯核心）→ 修订（改写补充）本应层层递进，却做成三个并列导航，产物靠手动选择/下拉传递，用户在页间反复跳。
2. **同类「内容来源」分散**：视频链接提取在"加工"页，订阅博主在"知识库"页——都是"把外部内容拿进来"，用户不会去知识库找订阅。
3. **配置与术语割裂**：提纯模式/迭代轮数在"设置→精读后端"，产物操作在加工页；"加工/精读/修订/提纯"多个词描述相邻概念。

## 二、改造策略：重做引导层，保留兼容骨架

**红线**：测试对 UI 有 109 条字符串断言，锁死 7 个 `data-page`、7 个 `page-X` 容器、页面物理顺序（home<process<kb<refine<revise<settings<about）及各锚点按钮归属段落。因此**不删页面、不改顺序、不挪锚点按钮、不新增/删除 API**。

在这个前提下做四件事：

| 改造 | 内容 | 效果 |
|---|---|---|
| 导航归组 | 7 个平级入口用 4 个分组标题包起来：获取内容（首页/加工）、加工流水线（精读/修订）、知识沉淀（知识库）、系统（设置/关于） | 侧栏一眼看出功能归属；折叠态自动隐藏分组标题 |
| 全局任务步骤条 | 页头下方加 4 步条「①获取内容→②提纯核心→③改写补充→④沉淀检索」，任意页可见、点哪跳哪、当前步高亮 | 流水线可视化，用户知道自己在哪一步、下一步去哪 |
| 加工页流程指引 | 加工页顶部加指引卡：去提纯 / 去改写 / 订阅博主·知识库，按钮直接跳转 | 订阅功能从"藏在知识库"变得可发现 |
| 术语统一 | PAGE_META 标题改为带阶段编号的表述（如「② 加工 · 提纯核心」「④ 沉淀 · 知识库」），副标题说清每步做什么 | 建立"获取→加工→沉淀"的统一心智模型 |

> **v1.8.5 编号统一（当前生效口径）**：上表是 S14 当时的四阶段方案，全局步骤条已于 2026-11-23 裁决移除，现只在首页保留三段流程条。因此编号收敛为一套主线：**① 获取 → ② 加工 → ③ 沉淀**。
> - 页头：`page.home=①`、`page.refine/revise=②`、`page.kb=③`（修订原③→②、知识库原④→③）；
> - 副标题：提纯/改写改为「加工流程第 1 / 2 步」，明确这是加工流程内的步骤号，不再出现游离的「第二步 / 第三步」；
> - 首页流程条维持三段主线编号（①取内容 / ②加工 / ③沉淀），②在加工页删除后改指向精读页。
> 真源在 `ui/i18n.js` 的 `zh` / `en` 手工段，`ui/app.js` 的 `PAGE_META` 同步镜像。
>
> **v1.8.5 文档加工位置调整**：加工页的「文档加工」卡片（核心提炼 / 导出 Word / 文档输入增强）迁入首页右栏「产物中心」上方——三者属于提取完成后的即时后续动作，放在产物旁比另开一页更顺手；三个按钮的 id 与事件绑定不变（全局 id 查找，与所在页无关）。同时首页概览结果卡取消 `min-height:200px` 与矮屏 `height:340px` 的固定空栏高，改为内容自适应。归属断言已在 `test_app.py` / `test_ui_layout.py` / `test_v162_layout.py` 同步更新，并新增 `test_ui_layout.py::test_10` 守护。
>
> **v1.8.5 加工页删除（当前生效口径）**：用户裁决「左侧加工导航与对应功能页多余」——三功能已迁首页产物中心、看板只是跳转入口，故将左侧 `data-page="process"` 导航项与整个 `page-process` 容器（三步看板）删除，页面骨架由 7 页收敛为 **6 页**（home / kb / refine / revise / settings / about）。首页流程条②「加工」的 `data-goto` 由 `process` 改为 `refine`（落到真正有功能的精读页），主线编号 ①→②→③ 不变；`syncStrip` 映射、命令面板项、CSS 图标色、i18n 中英 `nav.process`/`page.process.*`、`ui_rubrics.json` 判分页同步清理。这是 S14「不删页面」历史红线的用户裁决例外——旧红线原文保留可追溯，当前以 6 页契约为准；7 个测试文件的页数断言已同步，新增 `test_ui_layout.py::test_11` 守护 6 页契约。
