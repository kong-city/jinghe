## 五、风险登记（保留，不承诺消除）

1. **模型幻觉**：块号/old 文本有效只保证结构挂靠，不保证语义正确 → 分区呈现 + 显式标注「模型生成请核对」缓解，无法根除。
2. **真模型质量未验**：本轮全部 mock 验证工程逻辑；真实输出质量、prompt 效果、HTTP 兼容性需客户环境（ollama 或云端 key）验证。
3. **密钥泄漏**：已用独立文件 + 脱敏 + 零日志 + 测试锁死；剩余风险是本机文件系统层面的保护，属操作系统职责。
4. **纯 md 无真实颜色**：符号标记版靠 `[++ ]` / `[[~~ ]]` 区分，颜色仅在 html 版；UI 默认引导看 html 版。
5. **长任务体验**：模型推理可能数十秒；已有进度轮询 + 取消，但真机耗时未测。
