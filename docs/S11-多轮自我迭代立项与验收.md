## 一、需求与边界

用户诉求（2026-11-22）：完成 jinghe 未完成内容并优化，**先实现多轮自我迭代**。
确认口径为「两者都要」：① 提纯引擎新增多轮迭代能力；② 以多轮自检闭环推进本次改动。

**红线（继承 S8，逐轮守住）**：
- 每一轮的候选句都来自 `extract_engine.split_blocks / collect_sentences`，都是原文原句；
- 焦点只改**排序权重**，绝不生成新句；每轮产出都过 `verify_traceable`；
- 不改冻结内核 `extract.py`，不改 `extract_engine.py` 算法（该文件受 AST 测试锁定，仅标准库）；
- 新能力以**独立模块** `iterate_engine.py` 挂载，符合项目「冻结契约 + 独立模块」纪律。

## 二、实现

| 位置 | 变更 |
|---|---|
| `iterate_engine.py`（新增，约 300 行） | `iterate_core()` 多轮主流程；`_focus_from()` 共识焦点；`_build_candidates()` 基线候选（只算一次）；`normalize_rounds/normalize_jaccard` 脏值钳制；`render_rounds()` 产物轨迹追加 |
| `refine.py` | extract 分流读 `refine_rounds`，>1 轮走迭代引擎并传取消回调；多轮时在产物末尾追加「迭代轨迹」 |
| `backend.py` | `DEFAULT_CONFIG` + `_validate_config` + `public_config` 贯通 `refine_rounds`（默认 1，上限 5） |
| `app.py` | `/api/refine/backend` 透传 `refine_rounds`（无新增端点） |
| `ui/index.html` + `ui/app.js` | 设置页新增「迭代轮数」输入（1–5），LLM 模式自动置灰；保存/加载三处回显 |
| `build.spec` | hiddenimports 加 `iterate_engine`（防打包丢模块） |
| `tools/check_release.py` | 编译清单加 `iterate_engine.py` |
| `.github/workflows/ci.yml` | unittest 命令加 `test_iterate` |
| `test_iterate.py`（新增，11 项） | 默认等价 / 逐轮可回溯 / 真实重排+收敛 / 篡改拦截 / 取消 / 脏值钳制 / 零依赖 / 配置回环 / 端到端轨迹 / 接线契约 / 渲染只追加 |

**迭代语义**：轮 1 = 全文 `extract_core`（默认 1 轮时零行为变化）；轮 N = 以上一轮核心的**跨核心共识词**为焦点，对全文句子重打分 `score = 基线 × (1 + 0.85 × 焦点命中率)` 再跑 MMR。相邻两轮核心 text 集合 Jaccard ≥ 0.90 即判收敛早停。

**为何用「共识焦点」而非核心句全部二元组**：后者会覆盖语料绝大多数 gram，所有句子命中率接近，逐轮重排等于没发生（假迭代）。共识词（出现在多条核心里）才让焦点锐利、命中率有区分度——实测 `test_03` 第 2 轮 Jaccard=0.67 证明重排真实发生。

## 三、验收（2026-11-22，四轮自我迭代）

| 轮次 | 动作 | 结果 |
|---|---|---|
| 第 1 轮 | 全量测试 + 发版门禁 | 208/208 OK；门禁 16/16 |
| 第 2 轮 | 代码自审 | 发现并修复：脏 `converge_jaccard` 参数会抛 TypeError（新增 `normalize_jaccard` 钳制，并补回归测试）；清理未用 ctx 与重复分句 |
| 第 3 轮 | 安全边界审查 | 轮数全入口钳制 [1,5]（防 CPU 撑爆）；无新增 API 端点；取消令牌沿用 `_TASK` 无串扰 |
| 第 4 轮 | 端到端实测（源码服务 54399） | 配置 4 轮 → 实跑 2 轮收敛早停；产物含「迭代轨迹」与「原文原句」声明；事件流正确 |

红线复验：任意轮数（2/3/5）产出均通过 `verify_traceable`；篡改一条即被拦截；默认 1 轮与 S8 `extract_core` 逐字等价（零行为漂移）。
