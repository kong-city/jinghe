    加工流程指引
    
        
    这里是把内容转成 md 的工具。拿到 md 之后，继续用顶部步骤条走后面两步；想让软件自动追更多内容，去「知识库」页订阅博主。
    
        
    
          
          
          
        
    
      
    
      
    
        
    文档加工
    
        
    基于已提取的 Markdown 做进一步加工；Word / 音频 / 视频产物落 out/derived/，不改动 MERGED.md 等对账文件。
    
        
    
          
          
          
        
    
      
    

      
    
        
    音视频转写
    
        
    本机 whisper 转写音频、独立 video handler 提取视频三区块（元数据 / 音轨转写 / 画面·字幕）。缺工具时按钮显示「未启用」；绝不复用音频路径处理视频，绝不编造画面描述。
    
        
    
          
          
          
          
        
    
        
    
      
    

      
      
    
        
    视频链接 → .md
    
        
    粘贴视频链接（每行一条，最多 20 条），本机 yt-dlp 下载后复用视频提取生成三区块 .md，落 out/derived/。域名不设限，但内网 / 保留地址一律拒绝（SSRF 防护）。软件不内置任何账号凭据。
    
        
    
          
        
    
        
    
          
        
    
        
    
          
          
          
          
        
    
        
    
        
    cookie 文件仅只读传给本机 yt-dlp，不复制进产物、不写入日志、不外传；请仅处理你有权访问的内容。
    
      
    
    
    

    
    
    
      
    
        
    知识库
    
        
    把已产出的 Markdown 沉淀为可检索的知识条目，全部保存在本机（%LOCALAPPDATA%\Jinghe\kb），不联网、不外传。AI 补写内容默认不入库存。
    
        
    
          
          
          
        
    
        
    尚未探测知识库状态
    
      
    

      
      
    
        
    知识库维护
