      本机 whisper 把所选音频转成带时间戳的 .md（落 out/derived/）。音频文件从上方「文档 / PDF」输入区选择即可；缺工具时按钮显示「未启用」。
      
          
      
            
            
          
      
          
      
        
      
      
      

      
      
      
        
      
          
      视频来源
      
          
      本地视频与在线链接都产出三区块 md（元数据 / 音轨转写 / 画面·字幕）。独立 video handler，绝不复用音频路径，绝不编造画面描述。
      
          
      
            
            
          
      
          
      
            
      
              
              
            
      
          
      
          
      
            
      粘贴视频链接（每行一条，最多 20 条），本机 yt-dlp 下载后复用视频提取生成三区块 .md。域名不设限，但内网 / 保留地址一律拒绝（SSRF 防护）。软件不内置任何账号凭据。

      加工流水线
      
        
      对已提取的 Markdown 做二次加工。三步依次是「提纯核心 → 改写补充 → 入库检索」，每步都可独立重跑，不满意就回到上一步重来。
      
        
      
          
      
            
      
              1
              提纯核心
            
      
            
      从 md 里抽出核心知识点。默认抽取式：原文原句、逐字可回溯，零依赖离线。
      
            
      产出：核心 md 落 out/derived/
      
            
          
      
          
      
            
      
              2
              改写补充
            
      
            
      在提纯结果上做术语归一 / 合并去重 / 结构重排。可信模式只改写法不动事实；大模型模式可补写，改动以颜色标记。
      
            
      产出：修订稿 + 变更标记
      
            
          
      
          
      
            
      
              3
              入库检索
            
      
            
      把产物沉淀为本机知识库条目，可全文检索、按文档浏览块、点块回跳原文位置。
      
            
      产出：可检索条目 + 块级溯源
      
            
          
      
        
      
      
      
      
      
        
      文档加工
      
        
      基于已提取的 Markdown 做进一步加工；Word / 音频 / 视频产物落 out/derived/，不改动 MERGED.md 等对账文件。
